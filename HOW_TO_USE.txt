HOW TO USE: affect-register-atlas
====================================

PURPOSE
  Model the speaker's acoustic state transformations across baseline, tired,
  angry/combative, intimate, public/oratorical, inebriated, reading, and
  laughing-while-talking registers with exact delta matrices for F0, rate, SPL, and phonation.

CAPABILITIES
  - Standard 8-state register transformation taxonomy
  - Exact numerical delta matrix: ΔF0 (Hz/st), ΔSPL (dB), Δrate (%), ΔHNR (dB)
  - Phonation shifts: modal -> pressed/hyperfunctional, creaky/fry, or breathy/hypofunctional
  - Closed quotient (CQ) and spectral tilt (Alpha Ratio) adjustments per state
  - Supraglottic postures: larynx height displacement (mm) and velopharyngeal nasality
  - Output machine-readable register_matrix.json

USE CASES
  - "My voice clone sounds like a frozen interview take—make it sound angry / intimate / exhausted"
  - You need to dynamically switch vocal states during an interactive dialogue scene
  - You want to model how a speaker's voice degrades under fatigue or escalates in confrontation

IDEAS
  - Pair with synthesis-control-compiler to apply state deltas onto Kokoro or WORLD vocoder
  - Use combative/rally state when synthesizing large-venue public addresses
  - Use intimate/aside state for dramatic storytelling parentheticals

PROMPTS YOU CAN PASTE

  affect atlas for Steve Jobs
